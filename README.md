## Installing Deplo

Deplo is designed to run on your own infrastructure, giving you complete control over where your applications live and how they're managed.

Whether you're running a VPS, a dedicated server, or your own hardware, Deplo turns it into a powerful deployment platform without forcing you to become a full-time DevOps engineer.

### Installation guides

- [Install Deplo on a Linux server](https://deplo.build/docs/getting-started/install)
- [Deploy your first application](https://deplo.build/docs/getting-started/first-app)
- [Migrate from Coolify](https://deplo.build/docs/migrations/move-from-coolify)
- [Migrate from Dokploy](https://deplo.build/docs/migrations/move-from-dokploy)

## Building with Deplo

Deplo is built to make deploying applications simple without taking away control.

Connect your Git repository, configure your application, and deploy directly to your own infrastructure.

Whether you're deploying a personal project, a production application, or multiple services for a team, Deplo gives you the tools to manage everything from one place.

For more information, see the [Deplo documentation](https://deplo.build/docs).
