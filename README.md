## Get started

Run this as root on a fresh Linux server:

```bash
curl -fsSL https://deplo.build/install.sh | bash
```

Your dashboard comes up on a generated address like `https://deplo-cb00710a.deplo.site`, with HTTPS and no domain needed. Requirements, your own domain and every option are in the [installation guide](https://deplo.build/docs/getting-started/install).

> [!TIP]
> **No server yet? Get one with Deplo already on it.**
> Answer three questions at **[deplo.build/get-started](https://deplo.build/get-started)** and pick a plan from one of our hosting partners. No terminal: you get a link and create your account.
> Deplo earns a commission from the partner, and your price stays the same.

## What you get

- **Push to deploy** from GitHub, GitLab, Bitbucket or Gitea, or from an image, a Compose file or a plain upload.
- **A free URL from the first deploy**, then your own domains with certificates handled for you.
- **Databases** (Postgres, MySQL, MariaDB, MongoDB, Redis, ClickHouse) with encrypted, scheduled backups.
- **Built for teams**: fine-grained access for every member, an activity log, 2FA and API tokens.
- **The shell is optional**: useful for experts, never required.

Deplo is in beta: rough edges are expected, and 1.0 is planned for Q4 2026.
